# 中国运营商 Home Assistant 集成

在一个 HA 集成入口中添加中国移动 10086 和中国联通 10010 账号。**先选运营商，再填写对应账号信息**。每个账号是独立的配置项和设备，可以分别刷新、重新配置或删除。

本目录是单独的合并版；原有集成代码未修改。这里同时提供 HA 集成和中国移动浏览器加载项。完整步骤见 [安装与使用说明](INSTALL.md)。

## 安装

### HACS

在 HACS → 集成 → 右上角菜单 →「自定义仓库」中添加本仓库地址 `https://github.com/cumtwjq/china-carriers-ha`，类别选「集成」，然后搜索并安装「中国运营商」。重启 Home Assistant 后，按下方步骤安装移动加载项（仅移动用户需要）。

### 手动安装

从 [GitHub Releases](https://github.com/cumtwjq/china-carriers-ha/releases/latest) 下载完整包或相应的单独安装包，按 [安装与使用说明](INSTALL.md) 复制所需目录。在「设置 → 设备与服务 → 添加集成」中搜索「中国运营商」，然后选择运营商：

- **中国移动**：先安装并启动本目录的 `china_mobile_browser` HAOS 加载项。填手机号，随后填短信验证码；加载项负责浏览器登录和定时查询。合并版读取同一 `/share/china_mobile_10086` 目录，但会为新添加的账号建立独立浏览器会话。
- **中国联通**：只填 **OpenID**，不需要移动加载项。OpenID 的获取步骤见 [ha_unicom_bill 原项目 README 的“获取 OpenID”一节](https://github.com/Cyborg2017/ha_unicom_bill)。首次配置使用 15 分钟刷新间隔，只创建基础传感器；添加后可在该账号「配置」中修改刷新间隔（1–60 分钟）和详细传感器开关。

再次添加「中国运营商」可增加**另一个**账号。同一联通账号更换 OpenID 时，应在已有配置项的「配置」中替换，保留原设备和实体。OpenID 只填在 HA 配置页面，不要粘贴到聊天或公开问题单。

## 与原集成共存

合并版的域名是 `china_carriers`。它不会迁移或覆盖原集成的配置项和实体。原集成与合并版可以同时留在 HA，但如果同一号码在两个集成中各添加一次，HA 会显示两组设备和传感器；确认新集成工作正常后，可自行移除旧配置项。

联通原集成的自定义 Lovelace 卡片没有纳入合并版。合并版只提供 HA 原生传感器；如果旧卡片仍安装，它不会自动指向合并版设备。
